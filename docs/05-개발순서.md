# 개발 순서 문서 — 오늘 뭐 먹지?

## 1. 진행 순서
1. **환경 세팅**: `create-next-app`으로 TypeScript + Tailwind + App Router 구성 생성
2. **데이터 정의**: 카테고리별 메뉴 배열(`MENUS`)을 상수로 작성
3. **정적 UI 구현**: 제목, 카테고리 버튼, 결과 카드, 뽑기 버튼 레이아웃을 Tailwind로 배치
4. **상태 로직 연결**:
   - 카테고리 선택 상태 (`category`)
   - 표시 중인 메뉴 (`displayed`)
   - 확정 결과 (`result`)
   - 진행 상태 (`spinning`)
5. **뽑기 애니메이션 구현**: `setInterval`로 80ms마다 랜덤 메뉴를 표시하다가 1.4초 뒤 최종값 확정
6. **메타데이터 정리**: 페이지 타이틀/설명, `html lang="ko"` 반영
7. **개발 서버 검증**: `npm run dev` 실행 후 브라우저에서 카테고리 필터·뽑기 동작·콘솔 에러 여부 확인
8. **문서화**: 기획서 / UX 설계 / UI 설계 / 기술스택 문서 작성 (본 문서 포함)
9. **배포 (예정)**: GitHub public 레포 등록 → Vercel 배포 → 배포 URL 확보
10. **제출 (예정)**: 사이트 주소 + GitHub 레포 주소 제출

## 2. 검증 체크리스트
- [x] `npm run dev` 실행 시 에러 없이 구동
- [x] 카테고리 변경 시 해당 카테고리 메뉴만 뽑히는지 확인 (한식 선택 → 순두부찌개 등 한식 메뉴 확인)
- [x] 뽑는 도중 버튼이 비활성화되고 "뽑는 중..." 텍스트로 바뀌는지 확인
- [x] 브라우저 콘솔에 에러/경고 없는지 확인
- [ ] GitHub 레포 public 설정 및 최신 커밋 반영
- [ ] Vercel 배포 후 실제 배포 URL에서 재검증

## 3. 다음 작업자를 위한 메모
- 메뉴 목록을 늘리거나 카테고리를 추가하려면 `src/app/page.tsx`의 `MENUS` 객체만
  수정하면 된다. 별도 설정 파일이나 DB 마이그레이션이 필요 없다.
- 애니메이션 속도를 조절하려면 `handleSpin` 내부의 `spinDurationMs`, `tickMs` 값을
  바꾸면 된다.
- 향후 히스토리 저장 기능을 추가할 경우, [04-기술스택.md](./04-기술스택.md)에 정리된
  Supabase 테이블 스키마 초안을 참고할 것.
