# UI 설계 — 오늘 뭐 먹지?

## 1. 디자인 톤
기획 인터뷰에서 확정한 **미니멀/모던** 톤. 흰 배경 + 짙은 회색/검정 포인트 컬러 하나만
사용해 장식 요소를 최소화하고 콘텐츠(메뉴 이름, 버튼)에 시선이 집중되도록 구성.

## 2. 컬러 토큰
| 용도 | Tailwind 클래스 | 설명 |
|---|---|---|
| 배경 | `bg-zinc-50` | 전체 페이지 배경, 순백보다 은은한 톤 |
| 카드 배경 | `bg-white` | 결과 표시 카드 |
| 주요 텍스트 | `text-zinc-900` | 제목, 결과 메뉴명 |
| 보조 텍스트 | `text-zinc-500` / `text-zinc-600` | 설명 문구, 안내 텍스트 |
| 비활성/placeholder | `text-zinc-400` | 뽑기 전 `?` 표시 |
| 강조 버튼 | `bg-zinc-900` + `text-white` | Primary CTA, 선택된 카테고리 pill |
| 테두리 | `ring-zinc-200` | 미선택 카테고리, 결과 카드 아웃라인 |

## 3. 타이포그래피
- 제목: `text-3xl font-semibold tracking-tight` — 화면당 하나뿐인 헤드라인
- 결과 메뉴명: `text-3xl font-bold` — 가장 시선이 가야 하는 요소
- 본문/안내: `text-sm` — 보조 정보이므로 크기를 줄여 위계 구분

## 4. 컴포넌트 구성
```
Home (단일 페이지)
├─ Header (제목 + 부제)
├─ CategoryPillGroup (6개 버튼: 전체/한식/중식/일식/양식/분식)
├─ ResultCard (뽑기 결과 표시 영역)
├─ SpinButton (Primary CTA)
└─ ResultCaption (결과 확정 시에만 노출되는 안내 문구)
```
현재는 학습 목적상 컴포넌트를 분리하지 않고 `page.tsx` 한 파일에 두었다.
추후 기능이 늘어나면 `CategoryPillGroup`, `ResultCard`를 별도 컴포넌트로 분리 예정.

## 5. 레이아웃 & 반응형
- `max-w-md` 컨테이너로 모바일 우선 레이아웃, 데스크톱에서도 중앙 정렬된 카드형 UI 유지.
- 카테고리 버튼은 `flex-wrap`으로 화면 폭이 좁아지면 자동 줄바꿈.
- 세로 여백(`gap-8`, `py-16`)으로 각 섹션 간 시각적 구분을 확보.

## 6. 상태별 스타일 변화
| 상태 | 버튼 스타일 | 결과창 텍스트 컬러 |
|---|---|---|
| idle | `bg-zinc-900`, 활성 | `text-zinc-400` (`?`) |
| spinning | `disabled:opacity-60`, 클릭 불가 | `text-zinc-400` (빠르게 바뀌는 메뉴명) |
| result | 다시 활성화 | `text-zinc-900` (확정된 메뉴명) |
