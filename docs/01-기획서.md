# 기획서 — 오늘 뭐 먹지? (랜덤 메뉴 추천기)

## 1. 프로젝트 개요
매번 점심/저녁 메뉴를 고르는 데 드는 고민을 줄여주는 웹앱. 카테고리를 선택하고
버튼을 누르면 랜덤으로 메뉴 하나를 추천해준다.

## 2. 문제 정의
- "오늘 뭐 먹지"는 매일 반복되는 사소하지만 실제로 시간을 잡아먹는 의사결정이다.
- 선택지가 너무 많으면 오히려 고르기 어렵다 (선택의 역설).
- 결정을 랜덤에 맡기면 고민 없이 빠르게 행동으로 옮길 수 있다.

## 3. 타겟 사용자
- 점심/저녁 메뉴를 정하지 못해 매번 검색하거나 고민하는 직장인, 학생
- 특별한 학습 없이 바로 쓸 수 있는 가벼운 도구를 원하는 사용자

## 4. 핵심 기능 (MVP 범위)
| 기능 | 설명 | 우선순위 |
|---|---|---|
| 카테고리 필터 | 한식/중식/일식/양식/분식/전체 중 선택 | 필수 |
| 랜덤 추천 | 버튼 클릭 시 선택된 카테고리 내에서 랜덤 메뉴 1개 추천 | 필수 |
| 뽑기 연출 | 슬롯머신처럼 메뉴 이름이 빠르게 바뀌다 멈추는 애니메이션 | 필수 (기획 인터뷰에서 확정) |
| 최근 추천 기록 | 오늘 뽑았던 메뉴 리스트 표시 | 제외 (1시간 스코프 밖) |
| 회원가입/로그인 | 개인화된 추천, 히스토리 저장 | 제외 |

## 5. 스코프 결정 배경
기획 인터뷰에서 아래와 같이 확정했다.
- 카테고리 필터: **있음** (전체 랜덤보다 실용적이라 판단)
- 연출: **슬롯머신/룰렛 애니메이션** (단순 텍스트보다 재미 요소 추가)
- 추가 기능: **없음, 심플하게** (1시간 내 완성 가능한 범위로 제한)
- 디자인 톤: **미니멀/모던**

이 문서는 코드를 먼저 구현한 뒤 회고 형태로 정리되었다. 실제 AI 협업 과정에서는
`AskUserQuestion` 형태의 인터뷰로 위 항목들을 먼저 확정한 뒤 구현에 들어갔다.

## 6. 성공 기준
- 카테고리 선택 → 뽑기 → 결과 표시까지 3번의 클릭 이내로 완료된다.
- 별도 설명 없이도 첫 화면에서 사용법을 이해할 수 있다.
- 모바일 화면에서도 레이아웃이 깨지지 않는다.

## 7. 향후 확장 아이디어 (이번 스코프 밖)
- Supabase에 오늘 뽑은 기록 저장 → 최근 추천 히스토리 제공
- 사용자가 메뉴 목록을 직접 추가/삭제
- 위치 기반으로 근처 식당 연결
